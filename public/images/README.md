Estructura de imágenes de contenido

Uso recomendado

- hero/: imágenes principales de portada o cabecera.
- institucional/: fotos del equipo, sede, aulas o vida institucional.
- servicios/: imágenes para programas, actividades o servicios ofrecidos.
- galeria/: material fotográfico reutilizable para secciones o novedades.

Convención sugerida

- Usar nombres descriptivos en minúsculas y con guiones.
- Ejemplos: hero-portada-ajedrez.jpg, aula-principal.jpg, torneo-infantil-01.jpg

Nota

- Mantener copias optimizadas para web.
- Conservar originales de alta calidad fuera del repositorio si son muy pesados.
