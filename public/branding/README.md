Estructura de branding institucional

Uso recomendado

- logos/: versiones principales del logotipo institucional.
- icons/: favicon, apple-touch-icon y variantes cuadradas o simplificadas.
- social/: imágenes para Open Graph, tarjetas sociales y vistas previas.
- fonts/: archivos reales de tipografías institucionales para web.

Convención sugerida

- logos/logo-principal.svg
- logos/logo-principal.png
- logos/logo-horizontal.png
- logos/logo-simbolo.png
- icons/favicon.ico
- icons/apple-touch-icon.png
- social/og-image.jpg

Tipografía institucional definida

- Títulos y textos cortos: Helony.
- Textos largos y párrafos: Montserrat.

Nota

- Preferir SVG para logos cuando exista versión vectorial.
- Si se usa PNG, preferir fondo transparente y alta resolución.
- Para tipografías, usar los archivos web originales cuando estén disponibles.
