Tipografías de marca

Referencia actual de branding

- Tipografía para títulos y textos cortos: Helony.
- Tipografía para textos largos y párrafos: Montserrat.

Uso recomendado

- Colocar aquí los archivos reales de fuentes cuando estén disponibles.
- Preferir formatos web: `.woff2` y `.woff`.
- Si la licencia lo permite, conservar también la fuente original fuera del repositorio.

Convención sugerida

- helony/Helony-Regular.woff2
- helony/Helony-Regular.woff
- montserrat/Montserrat-Regular.woff2
- montserrat/Montserrat-SemiBold.woff2
- montserrat/Montserrat-Bold.woff2

Nota

- La referencia visual de la marca no reemplaza los archivos tipográficos.
- Hasta tener los archivos reales o una fuente web oficial, no conviene aplicar la tipografía de marca en producción.
